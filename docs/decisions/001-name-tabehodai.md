# ADR 001: the project is named tabehodai

Date: 2026-08-23. Status: accepted. Amended the same day: renamed from
hodai to tabehodai.

The name is hodai, from 放題 ("all you can", as in tabehoudai). It names
the product promise: unmetered agentic coding usage. Domains hodai.io and
hodai.net were available on 2026-08-23; a web search found no software
project, npm package, or startup using the name. 放題 is a suffix in
Japanese, so the standalone form reads as constructed; accepted.
Pronunciation is fixed as "hoe-DYE". hodai.io brands Eric's instance, not
the project, so the project stays forkable without trademark friction.

Amendment, 2026-08-23. The GitHub org "hodai" has been registered (and
dormant, zero public repos) since 2016-09, and GitHub does not release
dormant names without a trademark claim. The domain tabehod.ai was
available, and tabehodai (食べ放題, "all you can eat") is a real
standalone Japanese word where bare hodai was a constructed suffix. The
project, org, and domain are tabehodai / github.com/tabehodai /
tabehod.ai. The CLI binary and the npm and PyPI package names stay
hodai (short to type; npm hodai confirmed unregistered 2026-08-23).
hodai.io and hodai.net redirect to tabehod.ai. Pronunciation:
"tah-beh-hoe-DYE".
