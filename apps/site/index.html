tabehodai 食べ放題

A cohort pools a flat monthly payment and rents a GPU cluster that serves open-weight coding models. Each member gets an API key with concurrent session slots. Anyone can host a cohort.

01

Self-hostable infrastructure

The stack is defined as auditable infrastructure as code. A cohort can inspect it and run its own deployment.

02

Unmetered session slots

Members use assigned concurrent slots. Usage inside a slot is unmetered instead of billed per token.

03

Encrypted per-key cache

Each API key gets an encrypted KV cache. Cached context stays separated across members and keys.
